## 이 리포트가 답하는 질문

- 국세청은 가상자산을 **기술적으로 어디까지** 볼 수 있는가?
- 블록체인 분석 업체(Chainalysis, TRM Labs, Elliptic 등)의 도구는 **실제로 어떤 단계와 함수**로 동작하는가?
- 믹서·프라이버시 코인·크로스체인 브리지는 **수학적으로 어디까지** 추적 가능한가?
- 2027년 과세 시행 이후, CARF 정보교환은 **언제부터** 작동하는가?

## 페이지 구성

| 섹션 | 내용 |
|---|---|
| 6계층 아키텍처 | 공개정보로 재구성한 추적 시스템 구조 (TranSight · 국세청 통합분석시스템) |
| 포렌식 내부 동작 | UTXO 클러스터링, 디믹싱 수학(Tornado H1/H2/H3), EVM 추적, 그래프 ML |
| 상용 업체 프레임워크 | Chainalysis · TRM Labs · Elliptic · GraphSense 등의 공개 제품·API 비교 |
| 교육 커리큘럼 분석 | 업체 인증 과정이 공개하는 실제 수사 워크플로우 |
| 추적 시뮬레이터 | 레벨별 인터랙티브 자금 추적 체험 (합성 데이터) |
| 실제 사건 교차검증 | Welcome to Video · Tornado Cash · ChipMixer · Bitcoin Fog · Silk Road |
| 과세 프레임워크 | 2027년 시행 가상자산 과세 구조, CARF 시차, 1,461억 원 체납징수의 실제 메커니즘 |

## 추적 시뮬레이터

수사관의 워크플로우를 직접 클릭하면서 체험할 수 있는 시뮬레이터입니다.
모든 주소·거래 데이터는 **합성 데모 데이터**이며 실제 온체인 데이터가 아닙니다.

| 레벨 | 모드 | 할 수 있는 것 |
|---|---|---|
| 1 | 기본 가이드 | 자동 투어 — 단계별 설명을 따라가며 전체 흐름 파악 |
| 2 | 중급 분석 | 직접 홉 확장, 클러스터링 휴리스틱 on/off, 위험도 판독 |
| 3 | 수사관 모드 | H1/H2/H3 디믹싱 선택, 크로스체인 시나리오, Haircut/Poison/FIFO exposure 계산, 증거 JSON export |

상위 레벨로 갈수록 하위 기능은 그대로 유지되고 새 기능이 추가되는 누적형 구조입니다.
자세한 조작법은 [docs/simulator-guide.md](docs/simulator-guide.md)를 참고하세요.

## 연구 방법론

모든 주장은 아래 세 등급으로 구분됩니다.

- **검증됨** — 1차 자료(업체 공식 문서·개발자 문서·학술 논문·법정 문서·오픈소스)에서 직접 확인
- **업계 추론** — 공개 자료를 근거로 한 합리적 추론 (정확한 내부 수치·공식은 비공개이므로 일반 패턴으로 서술)
- **미확인** — 공개 자료에서 확인 불가 (페이지와 원자료에 명시)

상용 업체의 클러스터링 휴리스틱 전체 목록, 리스크 스코어 가중치, confidence 임계값 등은
어느 업체도 공개하지 않으므로, 이 리포트에서도 발명하지 않고 **비공개**로 표기했습니다.

## 면책

- 이 리포트는 공개 자료 기반 기술 분석이며 **세무 자문이 아닙니다**.
- 탈세·자금 은닉·추적 회피 방법에 대한 안내는 포함하지 않습니다.
