# 국세청 가상자산 추적 기술 심층 분석

국세청의 가상자산 추적·과세 프레임워크를 공개 자료 기준으로 해부한 인터랙티브 리포트 페이지.

## 구성

- **6계층 아키텍처**: 공개정보로 재구성한 추적 시스템 구조 (TranSight / 통합분석시스템)
- **포렌식 내부 동작**: UTXO 클러스터링, 디믹싱 수학(Tornado H1/H2/H3), EVM 추적, 그래프 ML
- **상용 업체 프레임워크**: Chainalysis · TRM Labs · Elliptic · GraphSense 등 공개 제품·API 비교
- **교육 커리큘럼 분석**: 업체 인증 과정이 공개하는 수사 워크플로우
- **추적 시뮬레이터** (레벨 1~3): 기본 가이드 투어 → 중급 직접 분석 → 심화 수사관 모드 (H1/H2/H3 디믹싱, 크로스체인, exposure 계산)
- **실제 사건 교차검증**: Welcome to Video · Tornado Cash · ChipMixer · Bitcoin Fog · Silk Road

## 참고

- 시뮬레이터의 주소·거래 데이터는 합성 데모 데이터이며 실제 온체인 데이터가 아닙니다.
- 수치·인용은 공개 자료(업체 공식 문서, 학술 논문, 법정 문서) 기준이며, 비공개 영역은 별도 표기했습니다.
- 세무 자문이 아니며, 탈세·은닉 방법에 대한 안내를 포함하지 않습니다.
