05 / ALGORITHMS

알고리즘 안쪽: 규칙 하나가 아니라 증거의 합성

상용 제품의 내부 산식은 비공개다. 아래는 학술 논문·공개 구현에서 검증된 신호와, 그 신호를 운영 시스템이 결합하는 일반 구조를 분리해 해부한 것이다.

검증된 원리

UTXO 클러스터: union-find + 예외 게이트

for tx in blocks:
if not CoinJoin(tx): union(all input addresses)
change = argmax P(output is change | features)
add_edge(cluster, change, confidence, provenance)
  1. CIOH: 같은 거래의 입력 주소를 공동 통제자로 가정하고 서로소 집합을 합친다.
  2. 잔돈 후보: 신규 주소, 입력과 같은 스크립트 타입, 비정형 금액, 출력 위치, locktime·RBF 변화 등을 점수화한다.
  3. 예외 게이트: CoinJoin·PayJoin이면 하드 병합을 막고, 약한 관계는 출처·근거가 남는 후보 edge로 보존한다.
  4. 전이 확장: 겹치는 입력집합과 후속 peel chain으로 엔티티 범위를 넓힌다.

06 / PRIVACY SYSTEMS

프라이버시 체인에서도 “무엇이 숨고 무엇이 남는가”를 분리한다

암호학적으로 감춰진 필드와 경계·네트워크·행동에서 남는 단서는 서로 다르다. 확률적 추정은 평문 복구나 개인 식별과 같은 말이 아니다.

Monero

링 16개 중 실제 입력 1개

  • Ring signature: 실제 입력 1 + decoy 15. key image로 이중지출만 방지하고 실제 입력은 공개하지 않는다.
  • RingCT: Pedersen commitment로 금액을 숨기고 Bulletproofs+ 범위증명으로 합 보존을 검증한다.
  • Stealth address: 수취인 공개키에서 one-time 주소를 만들어 실제 수취 주소를 체인에 노출하지 않는다.
  • Dandelion++: stem 소수 경로 뒤 fluff 확산으로 first-spy IP 추정을 약화한다.

OSPEAD의 기존 분포 기준 MAP decoder 평균 성공률은 23.5%(명목상 1/16=6.25%), effective ring size 4.2로 보고됐다. 제안 분포 적용 추정은 7.6%, 13.2다. 이는 평균적 최선 추정이며 개별 링 확정이 아니다. OSPEAD

Zcash

note commitment와 nullifier는 직접 연결되지 않는다

  • note commitment가 value·recipient·randomness를 숨겨 Merkle tree에 들어간다.
  • spend 시 nullifier를 공개해 중복지출을 막지만 commitment와 직접 연결되지 않는다.
  • zk proof는 note membership, spending key, nullifier 계산, 가치 보존을 증명한다.
  • transparent↔shielded 경계의 net value·시간·공개 주소는 보이지만 z→z 내부 sender·recipient·개별 금액은 보이지 않는다.

2018년 Sprout 사용행태 연구의 boundary analysis는 founder/miner 패턴 65.6%와 일반 휴리스틱 3.5%, 총 69.1%의 익명집합 축소를 주장했다. 현행 Orchard 등에 그대로 적용할 수 없는 시대·풀 종속 수치다. Kappos et al.
