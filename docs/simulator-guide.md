# 추적 시뮬레이터 가이드

`index.html` 하단의 인터랙티브 시뮬레이터 사용법입니다.
모든 데이터는 합성 데모 데이터입니다.

## 레벨 1 — 기본 가이드

- "다음 단계" 버튼으로 자동 진행되는 투어 모드
- 각 단계마다 왜 이 작업을 하는지 한 줄 설명이 붙습니다
- 조작 없이 전체 흐름(주소 입력 → 그래프 확장 → 패턴 탐지 → 지렛대 지점 식별)을 파악하는 용도

## 레벨 2 — 중급 분석

레벨 1의 전체 흐름 위에 직접 조작이 열립니다.

- **홉 확장**: 주소를 클릭해 앞/뒤 방향으로 자금 흐름을 직접 펼치기
- **휴리스틱 토글**: CIOH, change-address 탐지 등을 켜고 끄며 클러스터 경계가 어떻게 바뀌는지 확인
  - 단일 휴리스틱만 켰을 때의 오탐(false positive)을 직접 체감할 수 있습니다
- **위험도 판독**: 각 주소·클러스터의 exposure와 위험 카테고리 확인

## 레벨 3 — 수사관 모드

레벨 2의 모든 기능 + 심화 분석 도구.

- **디믹싱 휴리스틱 선택**: H1(주소 재사용) / H2(직접 전송) / H3(FIFO 시간근접)를 개별 적용하고 매칭률 변화를 비교
  - H3는 저신뢰 휴리스틱임을 시뮬레이터 내에서도 명시합니다
- **크로스체인 시나리오**: 브리지 이벤트 페어링(sequence/nonce/deposit ID)으로 체인을 넘나드는 흐름 추적
- **Exposure 계산 방식 비교**: Haircut(비례) / Poison(전체 오염) / FIFO(순서 기반) 중 회계 규칙을 바꿔 오염 금액이 어떻게 달라지는지 확인
- **증거 export**: 현재 그래프·타임스탬프·라벨을 합성 증거 JSON으로 내려받기

## 설계 원칙

- 상위 레벨은 하위 레벨의 기능을 모두 포함하는 누적형입니다
- "정답"이 하나가 아니라, 휴리스틱 조합에 따라 결과가 달라지는 것을 보여주는 것이 목적입니다
- 실제 상용 도구의 내부 가중치·임계값은 비공개이므로, 시뮬레이터의 수치는 **개념 이해용**입니다
