# 과세 유예 법안 워치 (Tax Bill Watch) — 감시 runbook

> 목적: 가상자산 과세 2년 유예 소득세법 개정안의 입법 단계를 매일 확인하고,
> 단계가 바뀌면 보고서의 `#bill-watch` 패널을 업데이트한다.
> 이 문서는 일일 체크 크론이 참조하는 정본이다. 기준일: 2026-11-18.

## 1. 추적 대상 (이것만 본다)

- **법안**: 소득세법 일부개정법률안, **의안번호 제2222597호**
  (안도걸 의원 등 10인, 2026-11-09 발의)
- **내용**: 가상자산 소득 과세 시행일 2027-01-01 → 2029-01-01 (2년 유예),
  결손금 3년 이월공제 신설(제46조의3), 사업자 시행준비 자료 제출 2027년부터
- **주의 — 번호 정정**: 초기 조사에서 제22597호로 잘못 적힌 적이 있다.
  정확한 번호는 **2222597**이다. 검색할 때 22597이 아니라 2222597을 쓴다.
- **혼동 금지**: 디지털자산기본법(금융위 소관 시장법, 정부안 11월 중 제출 전망)은
  별개 법안이다. 기본법 소식은 유예 법안 단계로 착각하지 않는다.

## 2. 현재 상태 (2026-11-18 기준)

| 단계 | 상태 | 날짜 |
|---|---|---|
| 1. 발의 | 완료 | 2026-11-09 |
| 2. 조세소위 심사 | **현재 단계** | 11/11 잠정합의(의결 안 됨), 11/17 후속 심사(의결 안 됨) |
| 3. 법사위 체계·자구 심사 | 대기 | — |
| 4. 본회의 | 대기 | — |
| 5. 공포·시행 | 대기 | 공포돼야 2029년 시행 확정 |

- **합의된 것 (11/17)**: 기본공제 250만 원 유지, 사업자 거래정보 제출 의무 조기 시행
  (개인 인적정보 제외, 동일 투자자 식별정보 포함 방향)
- **남은 쟁점**: 손실이월공제 기간 3년 vs 5년
- **다음 소위**: 11월 19~20일 개최 방향으로 잠정 합의된 것으로 보도됨
  (11월 15일 기준, 미확인 — 개최 여부 자체를 먼저 확인할 것)
- **데드라인**: 정기국회 12월 9일 종료. 연내 통과가 아니면 현행법상
  2027년 1월 1일 시행이 그대로 적용된다.
- **현행법**: 공포 전까지 시행일 2027-01-01, 취득가액 기준일 2026-12-31이 유효하다.

## 3. 매일 확인할 소스 (이 순서대로)

1. **국회 의안정보시스템** (likms.assembly.go.kr) — 의안번호 `2222597` 검색.
   심사 상태(소관위 심사 중 / 법사위 / 본회의 / 공포)와 회의 일자를 확인한다.
   미러: https://lawwatch.kr/bills/22-2222597 (단계·회의록 링크가 정리돼 있음)
2. **국회 회의록 시스템** (record.assembly.go.kr) — 재정경제기획위원회
   조세소위원회 회의록. 11/11 회의록은 이미 공개됨. 11/17·11/19~20분 확인.
3. **뉴스 검색어**: `가상자산 과세 유예 조세소위`, `소득세법 개정안 조세소위 의결`,
   `안도걸 2222597`, `가상자산 과세 유예 본회의`
   - 1차 출처: 디지털애셋(digitalasset.works), 헤럴드경제(mbiz.heraldcorp.com),
     한국경제(hankyung.com), 중앙일보, 뉴시스
   - 사설·칼럼의 "사실상 확정" 같은 표현은 의견이지 법이 아니다. 의결 사실만 본다.
4. **정부 후속 일정** (참고): 민관합동 워킹그룹, 내년 상반기 제도개선안,
   2027년 정기국회 법 개정안 제출, 2028년 상반기 세부 기준 발표
   (한국경제 2026-11-18 사설 기준).

## 4. 단계 변경으로 인정하는 기준

아래 중 하나라도 확인돼야 단계를 올린다. 보도 1건만으로는 부족하면 2건 이상
교차 확인한다.

- **조세소위 의결**: 소위 회의록 또는 간사(오기형·배준영) 발언으로 의결 확인.
  "잠정합의"는 의결이 아니다. "마지막 날 한 번에 의결" 예정이므로 소위
  마지막 날 결과를 특히 주시한다.
- **위원회 대안 등장**: 의원안 여러 건을 묶은 위원회 대안이 나오면 내용이
  개별 의원안과 달라질 수 있다. 대안 의안번호·내용을 새로 확인하고 패널에
  "위원회 대안으로 대체됨"을 명기한다. 대안도 같은 5단계를 다시 밟는다.
- **법사위 통과 / 본회의 통과 / 공포**: 각 단계는 회의록·본회의 표결 결과·
  관보 공포로 확인한다. **공포 전까지는 "추진 중"이다. "확정"은 공포 후에만.**
- **정기국회 종료(12/9) 후 미통과**: 패널을 "2026년 정기국회 미통과 —
  현행법상 2027-01-01 시행 유효"로 바꾸고, 다음 회기 일정을 미확인으로 적는다.

## 5. 패널 업데이트 방법

- **파일 4개**: `index.html`, `public/research-legacy.html` (한국어 쌍),
  `index-en.html`, `public/research-legacy-en.html` (영어 쌍).
  한국어 쌍끼리, 영어 쌍끼리 **바이트 동일**을 유지한다
  (`cmp index.html public/research-legacy.html` 등으로 확인).
- **위치**: 09A 규제 추적 섹션(`#regulation`) 맨 위, `id="bill-watch"` 패널.
  패널 안의 타임라인 5단계 중 현재 단계만 "현재 단계"로 표시하고 나머지는
  완료/대기로 둔다. 태그 날짜를 확인일로 바꾼다
  (예: `2026-11-18 확인 · 추진 중`).
- **출처 추가**: 새 사실마다 Sources 섹션에 `<li>`를 추가한다
  (제목에 날짜 포함, URL 원문 그대로).
- **동반 업데이트**: 09A 트랙 1(과세 유예와 손실 이월공제)과
  CARF 섹션의 유예 패널(1497행 부근)에 같은 사실이 있으면 문장을 맞춘다.
  서로 모순되게 두지 않는다.
- **검증**: `node --test tests/` + `npm run typecheck` + `npm run build -- --webpack`
  (순수 `next build`는 이 VM의 Turbopack 바인딩 문제로 실패, 기존 이슈).
  앵커 무결성(`#bill-watch` 등 모든 `href="#..."` 대상 존재)도 확인한다.
- **PR**: 브랜치에서 커밋·푸시 후 PR을 연다. **머지는 사용자 승인 후에만.**
